# Dashboard Data API

## User Value
Como participante de um projeto ativo, quero obter os dados agregados de
check-ins (evolução por meta, médias e sentimento recente) para visualizar a
evolução da dupla no dashboard.

## Acceptance Criteria
1. Novo endpoint `GET /api/projects/{id}/dashboard` retorna um `DashboardResponse`
   com: lista de participantes (com sentimento mais recente), séries temporais por
   `GoalField` (cada ponto = período, valor, usuário) e médias por meta por usuário.
2. O endpoint é gated behind a feature flag `Dashboard` (padrão R7): responde 404
   enquanto a flag estiver off.
3. Só participantes do projeto podem chamar o endpoint (403 caso contrário).
4. O sentimento retornado por participante é o do check-in mais recente
   (maior `PeriodNumber`); se não houver check-ins, `latestFeeling` é `null`.
5. A média de cada meta é calculada sobre todos os `CheckInMetric` daquele
   `GoalField` daquele usuário no projeto; se não houver dados, `averageValue`
   é `null`.
6. As séries temporais são ordenadas por `PeriodNumber` ascendente.
7. O endpoint retorna 404 quando o projeto não existe.
8. O contrato OpenAPI em `contracts/responsabilimano-api.yaml` é atualizado com
   o path e os schemas de resposta antes da implementação.

## Data Model
- Sem novas entidades ou migrations. Os dados são derivados de `CheckIn`,
  `CheckInMetric`, `GoalField`, `Project` e `User` já existentes.

## Response Shape (DTO)
```csharp
public sealed record DashboardResponse(
    Guid ProjectId,
    string ProjectName,
    List<DashboardParticipant> Participants,
    List<DashboardMetricSeries> Metrics);

public sealed record DashboardParticipant(
    Guid UserId,
    string Name,
    Feeling? LatestFeeling);

public sealed record DashboardMetricSeries(
    Guid GoalFieldId,
    string Label,
    string Unit,
    GoalDataType DataType,
    decimal? TargetValue,
    List<DashboardSeriesEntry> Series);

public sealed record DashboardSeriesEntry(
    Guid UserId,
    int PeriodNumber,
    DateTime SubmittedAt,
    decimal Value,
    decimal? AverageValue);
```

## Security Constraints
- Só participante do projeto pode chamar o endpoint. Validar server-side.
- Sem PII em logs (não logar e-mails/nomes na resposta).
- Antiforgery não aplicável (GET read-only).

## API / Event Contract
Adicionar `GET /api/projects/{id}/dashboard` ao contrato
`contracts/responsabilimano-api.yaml`. Schemas: `DashboardResponse`,
`DashboardParticipant`, `DashboardMetricSeries`, `DashboardSeriesEntry`.
O endpoint é gated behind `Dashboard` feature flag (404 while off).
